# План нагрузки строки

Табличный редактор веба задаёт нагрузку строки упражнения сразу на несколько недель: группы подходов (разминка,
топ-сет, рабочие, бэк-офф), чем задан вес (кг, % от e1RM, RPE, % от топ-сета, лесенка), прогрессия, разгрузка
и отдых. По плану клиент считает подходы каждой недели и пишет их в программу как обычные плановые подходы.

Сам план хранится в необязательном поле упражнения программы `loadPlan` (строка JSON до 8000 символов,
`planned_exercise.load_plan`, миграция 055). Одна и та же строка лежит у упражнения в каждой неделе строки, чтобы
план можно было открыть из любой недели. Сервер план не разбирает и не пересчитывает: хранит и отдаёт как есть.

Ручная правка недели не хранится отдельно: клиент сравнивает подходы недели с тем, что даёт план, и отличие
считает осознанной правкой тренера, которую пересчёт по умолчанию не трогает.

Старые клиенты (приложение до поддержки поля) при перезаписи программы теряют план, подходы остаются. Сначала
требуется развернуть сервер с миграцией 055, затем веб.
