# Расчёт целей подхода

Основа — лучший e1RM/ручной ПМ за 30 дней. Отсутствующий фактический RPE по-прежнему трактуется как 10.

Повторы и один из параметров «вес / процент / RPE» определяют остальные значения. Формула веса по RPE: `ПМ × curve(повторы + 10 − RPE)`. Используются существующие GENERAL/BENCH кривые; за их пределами автоматический вес не предлагается. Вес округляется до 2,5 кг, проценты — до целых. Старые дробные проценты совместимы с форматом хранения, но отображаются целыми.

Необязательное поле планового подхода `targetCalculation` хранит основу и ручные поправки: `rpe:weight`, `percent:rpe,weight`, `weight:`. Основа — `weight`, `percent` или `rpe`; после двоеточия — список ручных поправок автоматически рассчитанных полей. Правка такого поля меняет только его; правка основы/повторов обновляет только автоматические поля. Меню «Рассчитать по …» выбирает основу и снимает поправки, «Вернуть авторасчёт» снимает их для текущей основы. Пустое поле возвращается в автоматический расчёт.

Метаданные сохраняются в SQLite, программах, разовых планах и синхронизации. Старые клиенты могут потерять метаданные при перезаписи, значения сохраняются. Сервер не пересчитывает цели. Сначала требуется развернуть сервер с миграцией 042, затем новые клиенты.
