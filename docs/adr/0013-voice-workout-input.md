# ADR-0013: Голосовой ввод тренировки

Статус: принято владельцем 13.11.2026
Дата: 13 ноября 2026

## Контекст

Тренер планирует тренировку подопечному, ввод каждого подхода руками — много нажатий. Нужно: продиктовать
тренировку одной фразой и получить упражнения с подходами без уточняющих вопросов. Цели: медиана ≤ 3 с от
«Готово» до появления упражнений, p95 ≤ 6 с, ≤ 0,5 ₽ за диктовку, одна фраза — один результат.

## Решение

- **Синхронный запрос без очереди**: `POST /api/v2/voice/workout-parse`, звук в multipart. Идемпотентность —
  по `requestId` в памяти; суточный лимит — счётчик в БД.
- **Распознавание — Deepgram nova-3** за интерфейсом `SpeechRecognizer`, с подсказками словаря (`keyterm`).
  Сравнение на 12 живых записях тренера (Яндекс SpeechKit v1 и Deepgram, по два режима): Deepgram с подсказками
  — 1 % ошибок по словам, 9,4/10 по извлечённым полям, медиана 0,6 с, p95 1,2 с, без сбоев; Яндекс — 7–10 %,
  7,2/10, медиана ~2 с, p95 11–22 с из-за обрывов соединения (из контейнера вне России).
- **Разбор — детерминированный алгоритм**, не модель: словарь вариантов названий, основы слов, шаблоны
  параметров, проверка покрытия. Разбирает почти все фразы за миллисекунды, предсказуем и проверяем корпусом.
- **Модель — только для непонятых кусков** (DeepSeek за интерфейсом `GapResolver`), один короткий вызов со
  строгой схемой; каждый ответ сверяется с текстом своей дырки. Сбой модели не теряет разобранное.
- **Синонимы** системных упражнений — миграция; личные синонимы — из замен надиктованного упражнения.
- Звук и текст не хранятся и не логируются.

## Последствия

- Звук уходит в Deepgram (США): до выпуска — уведомление пользователю, проверка трансграничной передачи
  персональных данных и доступности с production-сервера. Провайдер заменяется реализацией интерфейса.
- Измерено на живых тестах: распознавание ~0,5–0,9 с, разбор < 20 мс, модель ~1,2–1,7 с (2,3 тыс. токенов
  входа). Цена модели по прайсу из `imports.md` — около $0,0008 за вызов; цену Deepgram нужно сверить с тарифом.
- Корпус фраз — регрессионный набор: правка шаблонов проверяется на всех 125 фразах.
